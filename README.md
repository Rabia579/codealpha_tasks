# CodeAlpha Machine Learning Internship Tasks

This repository contains my completed tasks for the **CodeAlpha Machine Learning Internship**.

## 📌 Tasks

### Task 1 — Handwritten Character Recognition
A deep learning project using CNN, TensorFlow, and Keras to recognize handwritten digits and letters from the EMNIST Balanced dataset.

**Key highlights:**
- CNN-based image classification
- 47 character classes
- Data augmentation
- Model evaluation using validation and test sets
- ~90% test accuracy
- Confusion matrix and per-class analysis
- Interactive handwritten character prediction demo

### Task 2 — Disease Prediction
A machine learning project for predicting disease from medical data.

**Key highlights:**
- Machine learning classification
- Data preprocessing
- Feature scaling
- Model training and evaluation
- Saved model and preprocessing components
